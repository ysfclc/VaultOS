# Keyboard language-resource provenance

_Status: no external lexicon or corpus approved or bundled yet._

Before adding frequency data for en-US, pl-PL or tr-TR, record for each source: publisher, dataset name and immutable version/revision, official source URL, license text or SPDX identifier, attribution and redistribution obligations, checksum, preprocessing commands, tokenization/normalization rules, and the resulting on-device resource size. Prefer sources that explicitly permit redistribution in an offline application. Do not infer a permissive license from a public download link. Keep raw source archives out of the repository unless the license expressly allows redistribution; commit only the permitted transformed resource and its provenance record. Never use private messages, contacts, clipboard history or user documents as corpus material.
