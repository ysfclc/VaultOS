### Public repository exposure — 2026-11-14

The repository metadata confirms `private=false` while `signing/vaultos-stable.keystore` remains tracked and `app/build.gradle.kts` contains static signing values. A new 0.13.1 build can demonstrate source/test/build correctness, but it does not remediate signing-key exposure. The owner must restore private repository visibility before further exposure; key rotation still needs a tested Android signing lineage and in-place update procedure. Do not uninstall VaultOS as part of this remediation.
